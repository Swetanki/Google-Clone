# Google Clone

A simple front-end clone of the Google homepage, built with HTML and CSS.

## Features
- Centered Google logo
- Rounded search input field
- "Google Search" and "I'm Feeling Lucky" buttons

## Tech Stack
- HTML5
- CSS3

## Getting Started
1. Clone or download this repository
2. Open `index.html` in your browser
